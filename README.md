# Retail Sales Data Analysis and Dashboard Using Microsoft Excel

## Project Overview
This project focuses on analysing retail sales data using Microsoft Excel. The purpose of the project is to understand sales performance, calculate important business metrics, and present meaningful insights through formulas, PivotTables, charts, and dashboard visualisations.

## Objectives
- Analyse retail sales and profit data.
- Calculate total sales, profit, and profit margins.
- Use Excel formulas and functions for data analysis.
- Summarise sales performance across different categories and regions.
- Create charts and visualisations to understand sales trends.
- Present key findings through an Excel dashboard.

## Tools and Technologies
- Microsoft Excel
- Excel Formulas and Functions
- PivotTables and PivotCharts
- Data Visualisation

## Key Features
- Sales and profit calculations.
- Conditional and logical functions.
- Lookup and reference functions.
- Date and text functions.
- Regional and category-wise sales analysis.
- PivotTables and charts.
- Interactive sales dashboard.

## Dataset
The project uses a retail sales practice dataset containing order details, product categories, customer information, sales, profit, discounts, and regional information.

## Project Files
- `Retail_Sales_Practice_Dataset(1).xlsx` – Excel workbook containing the dataset and analysis.

## Learning Outcomes
Through this project, I practised using Excel for data analysis, working with formulas, organising data, creating PivotTables, and presenting information through charts and dashboards.
