# 📊 Retail Sales Data Analysis and Dashboard Using Microsoft Excel

## 📌 Project Overview

This project focuses on analysing a retail sales dataset using Microsoft Excel. It involves working with sales records, applying Excel formulas and functions, analysing business data, and creating visual representations to understand sales performance.

The project explores different aspects of retail sales, including product categories, customer segments, regional performance, sales, and profit. It also uses PivotTables, charts, and a dashboard to present the analysis in an organised and understandable way.

## 🎯 Project Objectives

- Analyse retail sales and profit data.
- Calculate important business metrics using Excel formulas.
- Understand sales performance across different regions and product categories.
- Apply logical, lookup, text, and date functions.
- Summarise data using PivotTables.
- Create charts to identify sales patterns and trends.
- Present key information through an Excel dashboard.

## 🛠️ Tools and Technologies

- **Microsoft Excel**
- Excel Formulas and Functions
- PivotTables and PivotCharts
- Data Analysis
- Data Visualisation

## 📂 Dataset Description

The project uses a retail sales dataset containing 300 order records from the year 2024.

The dataset includes information such as:

- Order ID
- Order Date and Ship Date
- Customer Name
- Region and City
- Customer Segment
- Product Category
- Quantity
- Unit Price
- Discount
- Sales
- Profit

## 📈 Project Work

### 1. Basic Formulas and Functions
- SUM, AVERAGE, MAX and MIN
- COUNT and COUNTIF
- SUMIF
- Absolute and relative cell references

### 2. Logical and Conditional Functions
- IF and nested IF
- AND and OR
- COUNTIFS and SUMIFS
- AVERAGEIFS
- IFERROR

### 3. Lookup and Reference Functions
- VLOOKUP
- HLOOKUP
- INDEX and MATCH

### 4. Text, Date and Data Cleaning
- TEXT and WEEKDAY
- LEFT, RIGHT and MID
- UPPER, LOWER and PROPER
- TRIM and CONCATENATE

### 5. PivotTables and PivotCharts
- Category-wise sales and profit analysis
- Monthly sales analysis
- Region and segment-wise analysis
- Profit margin calculations

### 6. Charts and Dashboard
- Monthly sales trend visualisation
- Category-wise sales comparison
- Profit margin analysis
- Dashboard with multiple visualisations
